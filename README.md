# WoW Forever addons

A modified copy of **LayerSwap** for WoW Forever.

LayerSwap was written by **Adam5288** (version 1.14.58). This copy only changes a few settings.

## What's changed

- **Swaps per hour:** up to 100 instead of 16. The game itself may still refuse a move after 16 in an hour.
- **Swapping in combat:** allowed. The original blocks requests during a fight and for 6 s after.
- **Hosting:** off by default. It turns off at every login and after every swap that works. You can still turn it on yourself with the Host button or `/ls host`.
- **Leaving the host's party:** 1.5 s after joining instead of 4 s.

## Install

1. Click the green **Code** button above, then **Download ZIP**.
2. Open the zip and copy the `LayerSwap` folder into `World of Warcraft\_forever_\Interface\AddOns\`. If you already have LayerSwap, replace that folder.
3. Start the game, or type `/reload` if it's already running.

Updating LayerSwap from CurseForge will replace this copy with the original.
